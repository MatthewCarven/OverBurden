# The ideal-machines panel, 2026-09-29 — kept as it was

The working papers behind [../../IDEAL-MACHINES-PLAN.md](../../IDEAL-MACHINES-PLAN.md), kept because the plan
cites them ("the Core judge", "Reader C", "the gameplay design") and because the reader maps are
file-by-file maps of the machine code that the IM slices build on. Matthew, the same night: *"commit
anything you please to memory and/or markdown files along with anything we need saved"*.

**They are snapshots, not documentation.** Every `file:line` is against `main` at `71e6eed`
(2026-09-29), before IM-0b changed `MachineSet` and `IEditJournal`. **The plan is the decision**: where a
design or a verdict disagrees with it, the plan won, usually for a reason a judge or the critic gives
here. Nothing in this folder is maintained.

| Folder | What | Read it for |
|---|---|---|
| `briefs/` | What every reader, designer and judge was told: the numbered constraints and the deliverable | How the panel was run; the corrected constraints |
| `readers/` | Five maps: A the machine engine, B the plans and every decision already taken, C the inventory, the store and the identities, D what a creative mode touches, E materials | **Start here when building an IM slice.** Each ends with "Traps". |
| `designs/` | Four whole designs: 1 engine cost, 2 gameplay and the demo, 3 the mod format, 4 physical plausibility | The arms the plan did not take, and the grafts it did |
| `judges/` | J1 Core and the identities, J2 CPU, J3 gameplay and Matthew; each scores all four | Why a decision went the way it did; J2's ground figures |
| `critic/` | The completeness critic on the plan's first draft: ten must-fix findings, all folded in | What the first draft got wrong |
| `im0/` | IM-0's batch script and readers (the outputs were not kept; the tables are in the plan's "IM-0 — measured") | Re-running a measurement the same way |

The method is the design-shaping panel: readers, four designers from named angles, three one-lens
judges, a synthesis, a critic. The ladder's pass (M10-LADDER-PLAN) was the first; this was the second.
